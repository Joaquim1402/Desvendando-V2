# Desvendando o Céu Austral — protótipo estático com código-fonte

## Estrutura
- `index.html`: estrutura semântica da página.
- `src/styles.css`: estilos responsivos e identidade visual.
- `src/main.js`: menu móvel e galeria ampliada.
- `favicon.svg`: ícone vetorial, Cruzeiro do Sul branco sobre fundo azul-claro.
- `assets/southern-cross.svg`: símbolo vetorial da marca.
- `docs/LINKS-AUDIT.md`: auditoria dos hiperlinks e limitações de validação.
- `docs/link-manifest.json`: inventário de links externos presentes no site.

## Como abrir
Extraia o ZIP e abra `index.html` no navegador ou hospede a pasta inteira em um serviço estático.

## Imagens
As fotografias são carregadas da pasta pública de imagens da versão original no GitHub para manter o ZIP compacto. A conexão com a internet é necessária para carregá-las.

## Fonte do protótipo
O CSS e JavaScript estão separados na pasta `src/` para facilitar manutenção e edição. Este pacote é a versão estática do protótipo; não é o checkout completo da aplicação React/TanStack original, cuja estrutura usa `routes/`, `components/`, `assets/` e arquivos de configuração.

## Atualização visual e de conteúdo
- A seção de atividades apresenta as oito modalidades solicitadas: observação dos astros, foguetes educativos, oficinas pedagógicas, palestras científicas, Teatro Científico Experimental, Caravana da Astronomia, curso introdutório e turismo astronômico.
- As legendas usam fundo azul-escuro e texto claro para melhorar a leitura.
- As fotografias priorizam instrumentos e atividades práticas, reduzindo a repetição de fotos de grupo.
- O pacote completo mantém CSS e JavaScript separados e inclui favicon, símbolo da marca e documentação dos links.
